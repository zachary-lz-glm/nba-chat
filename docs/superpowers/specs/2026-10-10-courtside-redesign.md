# NBA Chat 场边看球助手

用户已批准 2026-10-10 对话中的设计方向并要求开始改版。

## 本轮范围

- 深海军蓝、米白、赛事红；首屏球馆摄影与非对称布局，输入框直接位于标题下。
- 首页今天 / 昨天 / 经典比赛选择，数据通过现有北京时间查数函数获取；经典固定查询 2025-06-23，必须明确历史日期。无比赛与失败分开显示，不伪造比分。
- 提供比赛、球员、关键回合三种真实可点击入口；会话与模型设置保持可用。
- 由工具结果恢复当前单场比赛上下文，切换历史会话和新建会话不会携带旧比赛。
- 工具数据渲染比赛卡、球员卡、单场统计、关键回合时间线，附相关追问；时间线标记球队比分顺序，支持加时节次，无数据不补写。
- 客观数据只从工具结果构造，卡片拒绝非法或错误输出；已取得数据不等于已核实全部事实。
- 用户侧不出现数据供应商、接口、字段名、比赛 ID；技术设置仍放设置面板。
- 生成中禁用追问以防重复发送；停止、重试、复制、中文输入法保护、移动端安全区域、减少动效保留。
- 现有 Next.js / React / AI SDK / Tailwind 栈与服务端事实、安全提示保留，无新框架。

## 非本轮范围

防剧透、晨报、偏好推荐、视频分析、会员和推送，以及线上发布。

## 验收

新增数据解析和上下文测试通过，原有测试通过，lint / TypeScript / 生产构建通过；浏览器核对桌面与手机首页、赛程切换、无数据、错误、对话、时间线、历史会话与停止。模拟回答必须明确用于验证，最终页面不预填模拟回答。

## 用户指定参考图修订

用户在部署后要求完整还原所附概念图，本修订覆盖此前自由调整的视觉选择：首页默认经典比赛，按 1146×868 桌面画框和 350×868 手机画框校准；全幅球场、右侧玻璃比分卡、深色输入框、红色按钮、横向赛事卡和手机分阶段入口。图片采用独立重建素材，球队徽标使用 NBA 官方公开资源。真实比赛数据、错误 / 空状态、会话与停止能力继续保留。
